# Керування службовими процесами зі спрямуванням журналів (b19-exec)

- Тривалі процеси (демони, сервери) мають stdout і stderr, автоматично спрямовані крізь структурований журналізатор.
- Кожен сигнал доходить до служби рівно один раз, тож `docker stop` плавно її завершує, а останні рядки журналу зберігаються.
- Рівні журналування для потоків stdout і stderr налаштовуються незалежно один від одного.
- Кілька демонів ділять один контейнер: кожен рядок позначено його демоном, вони зупиняються у зворотному до запуску порядку, а збій обовʼязкового демона зупиняє контейнер, щоб спрацювала політика перезапуску.
- Режим passthrough передає власний журнал служби збирачеві байт у байт, тож парсери, зроблені для цього демона, далі збігаються.
